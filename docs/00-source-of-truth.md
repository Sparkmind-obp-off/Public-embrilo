# 00 — Public Source of Truth

## Positioning hypothesis
Embrilo helps Indonesian small businesses and creators turn a product/service brief into practical, human-reviewed short-form content packs.

## Public responsibilities
Explain scope and process; show approved services; collect briefs and consent; confirm receipt; show customer-owned status; deliver approved work securely.

## Not promised in MVP
Full video rendering, social auto-publishing, guaranteed reach, guaranteed sales, or virality.

## Core journey
Discover → understand service → select offer → submit brief → receive reference → track status → retrieve approved delivery → request eligible revision.

## Customer-safe statuses
Received, Being reviewed, In production, Quality check, Ready, Delivered, Need more information. Never show internal notes, provider logs, prompt contents or raw stack traces.

## Definition of done
A mobile user understands the offer, submits a valid brief, receives a reference, securely sees their own status and approved result, and cannot access another customer's data.
