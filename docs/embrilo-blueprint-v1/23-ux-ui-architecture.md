# 23 — UX/UI Architecture
## Public navigation
Home, Layanan, Showcase/Hasil Karya, Cara Kerja, FAQ, Track Pesanan (only when implemented), Support, Privasi, Ketentuan.

## Homepage order
Clear outcome/CTA; service cards; curated showcase; process/quality/revision/delivery; FAQ/support/legal. Services take priority; showcase is second.

## Three separate experiences
- **Catalog:** what can I order, receive, price/timing/terms? Show outcome, fit, scope, fixed price or quote status, validated timeline and CTA.
- **Pre-purchase:** discover → inspect scope → select package/request quote → guided brief → review → terms → submit → checkout/quote approval. No forced account before browsing.
- **Showcase:** selected output, use case, output type and honest origin label; CTA to related service. Not purchasable unless configured as an offer.

## Service detail
Outcome, audience, exact deliverables, formats/quantity, customer inputs, exclusions, timeline/dependencies, revisions, price/quote, examples, FAQ, CTA.

## Brief
Progressive steps: goal/use; audience/brand; format/platform/language; references/assets; constraints; contact/consent; review. Ask only necessary data; label required/optional; preserve input; contextual validation; never request passwords.

## Visual system
Premium, clean, elegant, modern, readable; real approved output previews; mobile-first; keyboard support, visible focus, contrast, alt text, reduced motion. Track detail-to-brief, completion, conversion, checkout, quote acceptance and abandonment reasons.
