# 28 — Showcase & Portfolio Governance
Showcase is a curated capability layer, not a service catalog, private order history or dump of generated files.

## Origin labels
demo (illustrative, label Demo); internal_sample (label Sample); pilot; customer_work (only with documented permission); case_study (verified claims and metrics).

## Metadata
Title/context/category/service, origin, creation/version, approved preview, rights record, reviewer/approval, disclosure label, alt text, publication date and takedown owner.

## Publication workflow
Generate → QC/rights review → remove customer/personal/confidential data → verify source/license → get separate explicit permission for customer work → prepare safe preview → label → publish → record version and takedown route.

Payment does not grant marketing rights. Permission records scope, channels, attribution and expiry/revocation. Private deliverables stay behind customer-bound access; public previews are separate derivatives. No fabricated testimonials, logos, customers, revenue or performance metrics. Case metrics need source, period, baseline and permission.
