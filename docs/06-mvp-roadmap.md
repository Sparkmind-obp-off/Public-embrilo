# 06 — Public MVP Roadmap

## Phase 0 — Demand validation
Create one offer and sample pack; manually fulfil 3–5 pilots; measure actual payment, quality, time and revisions.

## Phase 1 — Brochure
Home, Services, How It Works, Examples, FAQ, Privacy and Terms. No fabricated proof. Acceptance: mobile responsive, accessible, fast and accurate.

## Phase 2 — Intake
Brief form, consent, server validation, idempotent submission, request reference and safe error/retry states. Acceptance: duplicate retry does not create duplicate order.

## Phase 3 — Status and delivery
Customer-bound status, approved assets, secure downloads and revision requests. Acceptance: cross-customer access denied and unapproved files hidden.

## Phase 4 — Conversion improvement
Track aggregate funnel: landing views, service views, form starts/completions, qualified requests, accepted deliveries, paid conversion when payment exists, repeat requests.

## Phase 5 — Commerce
Add checkout, payment, receipts, cancellation/refund and reconciliation only after offer and price are validated. Provider is undecided; no live credentials in Git.

## North Star
Qualified requests that become accepted, successfully delivered customer work. Guardrails: quality, turnaround, repeat use, contribution margin and zero privacy incidents.

## Launch gate
Approved copy/scope; reviewed privacy/terms; connector authentication tested; end-to-end tests pass; cross-customer access denied; mobile accessibility checked; integration claims reflect verified behavior; deployment health verified.
